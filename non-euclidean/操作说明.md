# 非欧几里得空间探索 · 操作说明

一个纯前端（单文件 `index.html`）的第一人称非欧几里得空间浏览器：在欧氏、球面 S³、双曲 H³
以及「五个直角房间」中自由飞行或沿地面行走，右上角实时显示投影到欧氏平面的地图。

直接用浏览器打开 `index.html` 即可（`file://` 双击可用，无需服务器、无外部依赖）。

---

## 1. 四种空间

| 空间 | 说明 |
| --- | --- |
| 欧氏（校准） | 普通三维空间，含棋盘地面与球体点阵，用于对照与校准 |
| 球面 S³ | 三维球面，{4,3,3} 超立方体蜂巢（立方体胞腔） |
| 双曲 H³ | 双曲三维空间，{5,3,4} 正十二面体蜂巢 |
| 直角房间 {4,5} | 双曲平面上的正方形房间，每个角 90°，每个顶点汇聚 5 个房间 |

按 **M** 键循环切换；切换时屏幕中央会弹出空间名，左上角 HUD 的「空间」行同步更新。

每个蜂巢胞腔 / 房间都被赋予互不相同的颜色。在 S³ / H³ 中飞越墙面、或在 {4,5} 中穿过
门洞进入相邻房间时，整片墙面会随之换色，直观呈现「不断走进不同房间」的非欧体验。
{4,5} 房间带天花板、加厚的墙体、带门楣与门套的门洞，以及天花板中央的发光灯盘；
墙角与天地接缝有环境光遮蔽，比早先更封闭、更有层次。透过门洞能看到相邻房间的不同颜色与其灯盘。

## 3. 步行模式

按 **G** 进入步行模式后：

- 相机被重力约束在「脚下最近的墙面/地面」上方固定眼高处；
- W/A/S/D 沿脚下表面（水平面）移动，可翻越棱线、穿过房间门洞；按住 **Shift** 跑步加速；
- 脚步**节奏与步速联动**（步频 = 步速 ÷ 步距），跑起来步子更快、音调更高更短促；
- 在 {4,5} 房间中**撞墙会被挡住**（只可经由门洞通行），不会穿模；
- 门洞底部有**门槛**；步行跨过门槛时会**自动上/下台阶**（撞到矮坎也会尝试自动抬腿迈过）；
- Space/Shift 与 Q/E 滚转被禁用；
- 视角俯仰不会影响重力方向（重力方向与视线解耦）。

在 {4,5} 房间中（飞行或步行）相机被硬性限制在房间内：既不会穿出**地板**，也不会穿出**天花板**。

步行时会按累计位移触发**脚步声**（WebAudio 实时合成，无外部音频文件；每约 0.8 测地距离一步）。
声音会**随脚下材质变化**：
- 欧氏 / {4,5} 房间：木质地面（低沉闷响），走到**门槛**上是清脆“嗒”声；
- H³：**雪地**（闷、柔的“沙沙”声），靠近棱线转为清脆声；
- S³：**金属**（清脆带余响的“叮”）。
另有随空间变化的低频**环境音**。
首次点击画面时会自动启用音频；按 **V** 开关（脚步 + 环境音）。

再按一次 **G** 回到飞行模式。

## 4. HUD 与地图

**左上角 HUD** 显示：当前空间与模式、帧率、渲染分辨率、相机坐标（非欧空间为四维坐标 `(x, y, z; w)`）。

**右上角地图** 把当前位置投影到欧氏平面：

- 球面 S³：立体投影，并叠加 {4,3,3} 蜂巢（四维超立方体）的 32 条棱骨架；
- 双曲 H³：庞加莱圆盘（保角）或克莱因圆盘（测地线为直线，按 K 切换），
  并叠加 {5,3,4} 蜂巢的棱骨架构投影；
- 直角房间 {4,5}：展开的 {4,5} 镶嵌（正方形房间网格）；

以上三种非欧地图均**以相机为中心、随视角旋转**（相机坐标系重定心），始终显示相机周围的胞腔结构。
H³ 的蜂巢骨架还会**按离相机的距离淡化**（越远越淡），并**按视线方向高亮**（正前方的棱最亮），
一眼看清你正对的方向。

地图可用鼠标**拖拽平移**、**滚轮以指针为中心缩放**、**双击复位**（也可用 `[` / `]` 键以中心缩放，
范围 40%–400%）。触屏上同样支持**单指拖拽平移、双指捏合（以两指中点为心）缩放、双击复位**。
H³ 地图还会在每个近处胞腔中心标注**稳定编号**（按群轨道 BFS 顺序，按 L 开关）。
- 红点表示当前位置，浅色短线表示朝向，红色轨迹是走过的路径。

## 5. 触屏 / 移动端

在触屏设备（或加 `?touch`）上会自动启用移动端界面与操控：

- **左半屏**：按下出现虚拟摇杆，上推前进、下拉后退、左右平移；
- **右半屏**：拖动转动视角；
- 右下角按钮：**▲升 / ▼降**（按住）用于飞行升降，**步行**切换步行/飞行，**空间**循环切换空间，**声音**开关声音；
- 会自动按设备像素比（上限 1.5×）提高渲染分辨率、缩小右上地图并隐藏键盘帮助条；
- 小地图同样支持单指拖拽平移、双指捏合缩放、双击复位。

## 6. 命令行参数

在地址栏 URL 后追加：

| 参数 | 作用 |
| --- | --- |
| `?space=0/1/2/3` | 启动时进入指定空间 |
| `?walk` | 启动即进入步行模式 |
| `?selftest` | 运行内建自动化自检并把结果写入页面 DOM |
| `?noaa` | 关闭静止帧时间超采样抗锯齿（用于对比画质 / 排查性能） |
| `?nosound` | 关闭脚步声 |
| `?zoom=2` | 启动时设置小地图缩放倍数 |
| `?touch` | 强制启用触屏界面（用于桌面调试） |

例：`index.html?space=2&walk`（双曲空间、步行模式启动）。

## 7. 性能提示

- 画质分四级（键 **1-4**，HUD 显示当前档位）：
  1 性能（40%·48步·关AA）／ 2 均衡（50%·64步·开AA，默认）／
  3 高（75%·96步）／ 4 极致（100%·128步）。步进数越多，曲面/蜂巢远处越精确。
- 按 **0** 开启自动画质（档位显示为「自动」）：帧率偏低时依次降**分辨率 → 步进数 → 关闭抗锯齿**，
  帧率回升时反向恢复，使步进数与 AA 一同联动，尽量稳住帧率。
- 相机**静止**时会自动进行时间超采样抗锯齿（逐帧亚像素抖动累积，约 1 秒内收敛到平滑图像）；
  一旦移动立即重置，因此移动时开销不变；按 `?noaa` 可关闭。

---

## 8. 自动化自检

运行仓库中的 `selftest.ps1`（Windows PowerShell + 无头 Chrome），会依次自检四种空间并输出结果，
包括：框架正交性、测地线推进距离、蜂巢折叠正确性与折叠不变性、命中距离、步行眼高稳定性、
地图投影公式等。全部通过时输出 `ALL PASS`。
