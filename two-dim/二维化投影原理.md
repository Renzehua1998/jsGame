# 二向箔 · 二维化投影原理

本文记录本项目中「三维物体 → 二维平面」的投影/降维算法。所有变换都在
**GPU 顶点着色器**中完成，`position` 缓冲区自始至终保存物体的**原始三维坐标**，
每帧只更新 `u_time` 一个 uniform。

对应源码：`index.html` 中的 `VERTEX_SHADER`（顶点）与 `FRAGMENT_SHADER`（片元）。

> **交互版本**：[`二维化数学原理.html`](二维化数学原理.html) —— 可在浏览器中拖动参数，
> 直观感受本文的每一条公式（mix / smoothstep / 指数膨胀 / CDF 重映射 / 线性外延 /
> 高斯冷却 / 全流程迷你模拟）。第 10 节为本文的直观图解版。

---

## 1. 坐标约定

| 记号 | 含义 |
| --- | --- |
| `p = (x, y, z)` | 粒子的原始三维坐标（物体以原点为中心） |
| `z` | **跌落轴**：二维平面最终垂直于 Z，平面本身是 XY 平面 |
| `p0 = (x, y)` | 粒子在 XY 平面上的投影 |
| `ρ0 = |p0| = √(x²+y²)` | 粒子到跌落轴的**投影半径** |
| `dir = p0 / ρ0` | 角向单位向量（保持不变的方向） |
| `R = u_radius` | 物体的特征半径（每个物体配置里给出） |

降维的本质可以概括为：

```
r2 = mix(ρ0, ρ2, q)      // 投影半径：原位 → 膨胀后的目标半径
z2 = mix(z0, planeZ, q)  // 高度：原位 → 塌缩到跌落面
xy2 = dir · r2           // 角向不变，只改变半径
```

即：**角向不变、半径重映射、Z 塌缩**。下面逐项展开。

---

## 2. 光速跌落面与碰撞检测

二向箔以速度 `u_speed` 沿 −Z 方向推进一个平面：

```glsl
float planeZ = u_startZ - u_speed * u_time;
planeZ = max(planeZ, u_endZ);          // 推进到底后停住
float swept = p.z - planeZ;            // ≥0 表示该粒子已被平面扫过
float q = smoothstep(0.0, u_band, swept);
```

- `swept ≥ 0`：粒子位于平面「上方（已被扫过的一侧）」，应被压入二维。
- `q = smoothstep(0, u_band, swept)`：把「是否被扫过」软化为 **0→1 的降维进度**，
  过渡带宽 `u_band`，避免整块瞬间跳变。
- 粒子在平面刚接触时尚 `q≈0`（仍是立体），随平面推过 `u_band` 距离后 `q→1`
  （完全二维化）。

三维形状消失、面积暴涨的过程，全部由这个 `q` 驱动。

---

## 3. Z 轴压扁

```glsl
float z2 = mix(p.z, planeZ, q);
```

`q=0` 时 `z2=z0`（原位）；`q=1` 时 `z2=planeZ`（贴到跌落面上）。
于是所有被扫过的粒子逐渐「拍」进同一个 XY 平面，形成一张二维薄片。

因为 `planeZ` 随时间下降，**先被扫到的是 z 较大的粒子**，二维盘因此像是
从上方一层层向下「摊开」。

---

## 4. 面积膨胀：从球体到实心盘（质量守恒）

### 4.1 膨胀因子

```glsl
float growth = exp(u_exp * q);
```

指数型膨胀：`q` 从 0 到 1 时，半径放大 `exp(u_exp)` 倍，**面积**放大
`exp(2·u_exp)` 倍——这正是「三维坍缩成二维、体积重排」时面积必须变大来
容纳原质量的可视化。

### 4.2 主体（球）的面积均匀映射

球体均匀取样后，沿 Z 方向正交投影到 XY 平面，其**投影面密度不是常数**：

```
σ(ρ) ∝ 2·√(R² − ρ²)      (ρ ≤ R)
```

中心最密（弦长最长）、边缘最疏。如果直接把 `ρ` 线性或幂次放大到目标半径，
就无法得到「表面密度恒定」的实心盘——尤其幂曲线 `r = R·f·(ρ/R)^α`（α<1）
在 `ρ→0` 处导数发散，会把粒子全部甩到边缘，**掏空盘心**。

正确的做法是做 **CDF（累积分布）重映射**：让目标半径的平方正比于
「投影半径 ≤ ρ0 的粒子占比」，这样目标盘内单位面积的粒子数才相等。

**推导体积占比 `cdf(ρ0)`**

球内满足 `x²+y² ≤ ρ0²` 的粒子体积：

$$
V(\rho_0)=\int_0^{\rho_0} \underbrace{2\sqrt{R^2-\rho^2}}_{\text{弦长}}\cdot \underbrace{2\pi\rho\,d\rho}_{\text{环面积}}
=\frac{4\pi}{3}\Big(R^3-(R^2-\rho_0^2)^{3/2}\Big)
$$

总体积为 `4πR³/3`，故

$$
F(\rho_0)=\frac{V(\rho_0)}{V(R)}
=\frac{R^3-(R^2-\rho_0^2)^{3/2}}{R^3}
$$

与着色器中的一行完全一致：

```glsl
float inner = max(R2 - rho0 * rho0, 0.0);
float cdf   = (R3 - pow(inner, 1.5)) / R3;
```

**目标半径**

实心盘要「表面密度恒定」，则盘内目标半径 `r` 以内的粒子占比应为
`(r / r_out)²`。令它等于 `F(ρ0)`：

$$
\Big(\frac{r}{r_{out}}\Big)^2 = F(\rho_0)
\;\Longrightarrow\;
r = r_{out}\sqrt{F(\rho_0)}
$$

```glsl
frac = sqrt(clamp(cdf, 0.0, 1.0));
```

### 4.3 主体之外的结构（行星环等）

球外（`ρ0 > R`）改用**线性外延**：

```glsl
frac = 1.0 + (rho0 - u_radius) / u_radius;   // = ρ0 / R
```

于是 `ρ2 = R · growth · (ρ0/R) = growth · ρ0`——即外侧结构被**整体等比放大**，
保持相对构型。这样行星环不会被压到与盘缘重合而消失，而是继续留在二维盘之外，
成为一圈独立的环。两段映射在 `ρ0 = R` 处连续（都给出 `frac = 1`）。

### 4.4 合成目标半径

```glsl
float rho2 = u_radius * growth * frac;   // 完全二维化后的目标半径
float r2   = mix(rho0, rho2, q);         // 未扫到时保持原位
```

## 5. 完整顶点变换（伪代码）

```
planeZ = clamp(u_startZ - u_speed·u_time, ... , u_endZ)
swept  = z0 - planeZ
q      = smoothstep(0, u_band, swept)

ρ0  = |(x0, y0)|
dir = (x0, y0) / ρ0            // ρ0≈0 时取 0

growth = exp(u_exp · q)
if ρ0 ≤ R:
    cdf  = (R³ - (R² - ρ0²)^1.5) / R³
    frac = sqrt(cdf)
else:
    frac = 1 + (ρ0 - R)/R

ρ2 = R · growth · frac
r2 = mix(ρ0, ρ2, q)
xy2 = dir · r2
z2  = mix(z0, planeZ, q)

gl_Position = P · V · (xy2, z2)
```

## 6. 颜色、冷却与辉光

片元着色器根据「距开始降维的归一化时间」`vSince = swept / u_band` 决定亮度：

```glsl
heat   = vSince > 0 ? exp(-vSince² · u_cool) : 0   // 边界处≈1，随后衰减
cooled = clamp(vSince, 0, 1)                        // 冷却进度
galaxy = vColor · mix(1, 0.60 + 0.60·seed, cooled)  // 冷却后保留原配色 + 星点抖动
galaxy = mix(galaxy, min(galaxy, 0.92), cooled)     // 凝固后亮度 <1，不再持续发光
col    = mix(galaxy, vec3(3.5, 3.5, 3.7), heat)     // 跌落边界 → HDR 纯白
```

- `heat` 让正在被扫过的粒子输出 HDR 纯白（>1），`UnrealBloomPass` 阈值 `1.0`
  只提取这些高亮，形成刺眼闪光；冷却后亮度被压到 `<1`，停止辉光。
- 后期管线使用 HalfFloat 渲染目标以保留 >1 的亮度，否则会被裁到 1 而失去闪光。

## 7. 三维透视（X 光）模式

透视模式**不改变投影几何**，只改变渲染方式，因此对所有物体通用：

- 材质切换为 `transparent = true`、`depthWrite/depthTest = false`、
  `blending = AdditiveBlending`；
- 顶点着色器把逐粒子的**透视衰减系数 `aXray`**（默认 `1.0`）传给片元；`u_xray = 1`
  时按该系数压低单点强度

```glsl
// 顶点：vXray = aXray
// 片元：
float xk = mix(1.0, vXray, u_xray);          // 常规模式忽略 aXray
col      = mix(col, col * 0.45 * xk, u_xray);
alpha    = mix(1.0, 0.028, u_xray) * a * xk;
```

叠加混合 + 极低单点强度，使得**沿视线累积的密度**成为亮度（类 X 光照片）：
外壳变淡、内部结构（地核、太空城的城市与三颗太阳、战舰内部舱室、宇航员的骨骼与内脏）透出。

`aXray` 用于需要「看穿外壳」的物体：宇航员把它给宇航服 / 头盔设成 `0.05`（头部软组织 `0.35`），
于是 X 光下蛋白色的航天服几乎完全淡出、穿戴者的骨骼内脏清晰凸显；其余物体保持默认
`1.0`，透视表现与以前完全一致。

## 8. 可调参数

| 参数 | 含义 | 默认 |
| --- | --- | --- |
| `u_speed` | 跌落面推进速度 | 2.5 |
| `u_band` | 降维过渡带厚度（`q` 的软度） | 1.6 |
| `u_exp` | 面积膨胀指数（越大目标盘越大） | 3.5 |
| `u_cool` | 冷却速度（越大白热边界越窄） | 0.6 |
| `u_startZ` / `u_endZ` | 跌落面起止 Z | `R+6` / `−(R+10)` |
| `u_radius` | 物体特征半径 `R` | 随物体配置 |

被扫粒子的**最大目标半径**为 `R·exp(u_exp)`，相机 framing 使用物体的最大横向
半径 `currentExtent`（含行星环等外部结构），保证二维盘与盘外环都在画面内。

---

## 9. 为什么不需要重建几何 / 高效性

- 原始坐标恒定：`position`（和 `aColor`）只在切换物体时构建一次；
- 每帧只写 `u_time`，其余全是纯粹的顶点着色器算术；
- 150 万粒子在 GPU 上并行完成塌缩、膨胀与着色，CPU 端零逐粒子循环。

# 第 10 节（独立一页）· 直观图解：二维化用到的数学

> 前面各节是"精确版"。这一页用类比、图示和具体数字，把同一套数学讲给直觉。
>
> 一句话总览：**二维化 = 一层层拍扁 + 按面积把粒子重新摊匀 + 刚拍下时闪白光。**

把整个物体想象成一头蒜：

| 数学组件 | 在"拍蒜"里对应什么 |
| --- | --- |
| 跌落面 `planeZ` 下移 | 刀面从上往下压 |
| `mix(z0, planeZ, q)` | 蒜被压扁（高度归零） |
| `growth = exp(u_exp·q)` | 蒜泥必须摊成一张**更大的饼** |
| CDF 重映射 `frac = √cdf` | 摊饼的手艺——保证每处蒜泥**一样厚** |
| `heat = exp(−t²·u_cool)` | 刚被压到的那圈最烫最亮，随后冷却 |

```
      z（跌落轴）
      ↑
      │  ● ● ●          ● = 还没被扫到（保持立体，q=0）
      │ ● ● ● ●
 ┄┄┄┄┄│┄┄┄┄┄┄┄┄┄┄  planeZ(t)  ← 跌落面向下推进
      │  ★ ★ ★          ★ = 过渡带内（正在塌缩+膨胀，0<q<1）
      │   ★ ★
      │    ─────────    （完全二维化，q=1，粒子被"冻"在面上）
      └──────────────────→ x / y（最终的二维平面）
```

## 10.1 `mix(a, b, q)`：一根进度条

`mix` 就是"从 a 到 b 走了百分之多少"：`q=0` 取 `a`，`q=1` 取 `b`，中间线性过渡。

```
a ●━━━━━━━━━┿━━━━━━━━━● b
            q = 0.5
```

项目里两根进度条同时推进：

- 半径：`mix(ρ0, ρ2, q)` —— 还没被扫到时粒子停在原地；
- 高度：`mix(z0, planeZ, q)` —— 高度慢慢塌到跌落面上。

## 10.2 `smoothstep`：电梯式的缓入缓出

如果 `q` 直接等于"是否被扫过"（0/1 硬切），粒子会瞬间跳到二维，像电梯猛启猛停。
`smoothstep(t) = 3t² − 2t³` 两端斜率为 0——起步和停靠都柔和：

```
q ──────────────────────► swept
0.0 ●━━━╗
        ║  ╔═══════╗      ← 过渡带宽 u_band：先松动、再摊开
0.5     ╚══╬═══════╝
1.0         ╚━━━━━━━●
```

## 10.3 指数膨胀：复利式摊开

`growth = exp(u_exp·q)`：半径不是匀速变大，而是**按固定倍率连续翻倍**——像复利、
像滚雪球。注意面积 ∝ 半径²，所以面积实际放大了 `exp(2·u_exp)` 倍（默认约 1100 倍）。
这正是"三维坍进二维、体积重排为面积"时面积暴涨的直观来源。

## 10.4 CDF 重映射：按排名发座位（核心！）

**问题**：球投影到圆盘上"中心厚、边缘薄"（投影密度 ∝ 弦长 `2√(R²−ρ²)`）：

```
   球的俯视投影                我们想要的均匀盘
    ████████                   ░░░░░░░░░░░░
  ████████████               ░░░░░░░░░░░░░░
  ████████████      ──►      ░░░░░░░░░░░░░░   处处一样密
  ████████████               ░░░░░░░░░░░░░░
    ████████                   ░░░░░░░░░░░░
   （中心浓、边缘淡）
```

如果直接"半径按比例放"（线性），盘中心偏密、边缘偏稀；如果用幂曲线放大
（`r ∝ ρ^α, α<1`），中心区域的导数趋于无穷——轴心附近的粒子被**无穷放大地甩出去**，
盘心反而被掏空。

**正确做法**（和图像处理里的"直方图均衡化"完全同构）：

1. 把所有粒子按 `ρ0` 从小到大**排队**，算出累积占比 `cdf`（"前 k% 的粒子"）；
2. 均匀盘里，"第 k% 名"的粒子应坐在**面积占比 k%** 的半径上；
3. 而盘的面积 ∝ r²，所以 **`r = r_out · √cdf`** ——开根号就是把"面积份额"换算成"半径"。

用具体数字看（`R = 1`）：

| 投影半径 ρ0 | 累积占比 cdf（球里实际有多少粒子） | 均匀盘目标半径 √cdf |
| ---: | ---: | ---: |
| 0.25 | 9% | 0.30 |
| 0.50 | **35%** | **0.59** |
| 0.75 | 71% | 0.84 |
| 0.90 | 92% | 0.96 |
| 1.00 | 100% | 1.00 |

**读第二行**：一半半径的圆柱里装了 35% 的粒子（中心弦长长、粒子多）；而均匀盘
一半半径的圆只占 25% 的面积——装不下。所以必须把这 35% 往外推到 `0.59·r_out`，
让他们恰好占 35% 的**面积**。`√cdf` 干的就是这件事。

## 10.5 线性外延：等比放大照片

行星环等主体外的结构（`ρ0 > R`）不参与上面的"均衡化"，直接乘同一个放大倍数：
`frac = ρ0/R` ⟹ `ρ2 = growth · ρ0`。

直观：把整张照片**等比放大**——盘外的环仍然在盘外、相对位置不变、不会和盘缘
挤成一团；且在 `ρ0 = R` 处与主体映射无缝衔接（都等于 1）。

```
        ┌─────────────┐
        │   ██ 盘 ██   │        ○○○ 盘外的环（线性外延，
        └─────────────┘            随整体等比放大）
      ○○○           ○○○
```

## 10.6 高斯衰减：淬火

`heat = exp(−vSince² · u_cool)` 是一条钟形曲线：刚被扫过（`vSince ≈ 0`）时 ≈ 1，
输出 HDR 纯白触发辉光；稍微离开边界就迅速衰减为 0。

直观：铁匠淬火——只有**刚入水的那一条**最亮，往后迅速暗下去。`u_cool` 越大，
那条亮边越窄。

## 10.7 一个粒子的完整旅程（数值示例）

取 `R = 5`、`u_exp = 3.5`，某粒子原始坐标 `p = (1.8, 2.4, 2.0)`：

**第 0 步 · 预计算（与时间无关）**

- 投影半径：`ρ0 = √(1.8² + 2.4²) = 3.0`
- 角向：`dir = (0.6, 0.8)`（**从头到尾不变**）
- 均衡化系数：`inner = 25 − 9 = 16`，`cdf = (125 − 64)/125 = 0.488`，
  `frac = √0.488 ≈ 0.699`

**第 1 步 · 过渡带中（`q = 0.5`）**

- 膨胀：`growth = e^1.75 ≈ 5.75`，目标半径 `ρ2 = 5 × 5.75 × 0.699 ≈ 20.1`
- 当前期望：`r2 = mix(3.0, 20.1, 0.5) ≈ 11.5`
- 高度：落在 `z0` 与 `planeZ` 的中点——粒子"半悬"着，边塌边摊

**第 2 步 · 完全二维化（`q = 1`）**

- 膨胀：`growth = e^3.5 ≈ 33.1`，目标半径 `ρ2 ≈ 115.7`
- 落位：`xy2 = (0.6, 0.8) × 115.7 ≈ (69.4, 92.6)`
- 高度：`z2 = planeZ`，被"冻"在跌落面上

**结论**：这颗粒子最终落在与原方向**完全相同**的射线 `(0.6, 0.8)` 上、距轴约
116 处。整个二维化过程中，改变的只有两件事——**离轴多远**（半径重映射）和
**离面多高**（Z 塌缩）；"朝哪个方向"从未改变。
