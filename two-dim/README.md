## 二维化的数学模型

设粒子原始坐标为 `p = (x0, y0, z0)`，跌落面位置 `planeZ = u_startZ - u_speed·u_time`（推进到 `u_endZ` 后停止）。

1. **碰撞检测**：`swept = z0 - planeZ`，`swept ≥ 0` 表示已被平面扫过。
2. **降维进度**：`q = smoothstep(0, u_band, swept)`，由 0 平滑过渡到 1。
3. **Z 压扁**：`z2 = mix(z0, planeZ, q)`，粒子 Z 逐渐塌缩到跌落面。
4. **面积膨胀（质量守恒）**：保持角向 `dir = normalize(x0, y0)`，按半径分段映射：

   ```
   growth = exp(u_exp · q)                          // 整体指数膨胀
   // 主体（ρ0 ≤ R）：面积均匀映射为实心盘
   cdf    = (R³ - (R² - ρ0²)^1.5) / R³              // 球体投影中 ρ<ρ0 的粒子占比
   frac   = sqrt(cdf)                               // 面积均匀 ⇒ 目标半径 ∝ √cdf
   // 主体之外（ρ0 > R，如行星环）：线性外延，保持相对位置
   frac   = 1 + (ρ0 - R)/R
   rho2   = R · growth · frac
   r2     = mix(rho0, rho2, q)                      // 未碰撞时保持原位
   xy2    = dir · r2
   ```

   - 主体用 `r ∝ √cdf` 得到**表面密度恒定**的实心盘 —— 不会像幂曲线（`x^α, α<1`）那样把粒子全推到边缘、掏空中心。
   - 主体之外**线性外延**（而非 clamp）：行星环等外部结构被推到盘外的独立环，不会被压到同一边缘半径而消失。相机 framing 用物体的最大横向半径 `currentExtent`，保证环也在画面内。

所有计算都在 GPU 上完成，`position` 缓冲区始终保持原始坐标（每帧只更新 `u_time` 一个 uniform）。

## 辉光与能量释放（后期处理）

顶点着色器把「距开始降维那一刻的归一化时间」`vSince = (z0 - planeZ) / u_band` 传给片元着色器，片元中：

```
heat   = vSince > 0 ? exp(-vSince² · u_cool) : 0   // 边界处 ≈1，随时间衰减
cooled = clamp(vSince, 0, 1)                        // 冷却进度
col    = mix(galaxy, hotWhite, heat)                // 冷却色 → HDR 纯白
```

- `heat` 让刚被扫过的粒子输出 `vec3(3.5)` 的 HDR 纯白，`UnrealBloomPass` 阈值 `1.0` 只提取这些 >1 的高亮，形成刺眼闪光。
- `cooled` 让粒子在冷却时**保留物体原本的配色**（不再整体偏蓝），仅做明暗抖动形成星点；同时把亮度限制在 `<1`，避免凝固后持续辉光。
- 后期管线使用 **HalfFloat 渲染目标**，以保留 >1 的亮度，否则会被裁到 1 而失去闪光效果。

## 可调参数（`uniforms`）

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `u_speed` | 跌落面推进速度 | 2.5 |
| `u_band` | 降维过渡带厚度 | 1.6 |
| `u_exp` | 面积膨胀指数（越大圆盘越大） | 3.5 |
| `u_cool` | 冷却速度（越大白热边界越窄） | 0.6 |
| `u_startZ` / `u_endZ` | 跌落面起止 Z | +11 / -15 |

Bloom 参数在 `new THREE.UnrealBloomPass(...)` 处调整：`strength=1.0, radius=0.5, threshold=1.0`。

按 `R` 键可重放降维过程（会同时复位自动运镜）。用户一旦拖拽鼠标，自动运镜即被接管。

## 操作

- **点击「点击开始」按钮**（或按空格 / 回车）：开始降维
- **`1`–`7` 或左上角按钮**：切换观测目标（切换后回到启动界面）
- 左键拖拽：旋转视角
- 滚轮：缩放
- 右键拖拽：平移
- `[` / `]`：降低 / 提高播放倍率（慢速播放）
- `P`：暂停 / 继续
- `V`：切换远景「远端俯视」（一眼看全整个二维盘）
- `S`：切换「侧视」（贴着盘面看二维盘各部分的流动方向）
- `X`：切换**三维透视（X 光）**——粒子转半透明叠加，看穿外壳观察内部结构（所有星体通用）
- `R`：重放当前物体（回到启动界面）

## 三维透视（X 光）

按 `X` 开启透视后，粒子材质切换为 **半透明 + 叠加混合**（`transparent` / `depthWrite=false` / `AdditiveBlending`），片元着色器中的 `u_xray` 把颜色乘 `0.45`、并把单点 `alpha` 压到 `0.028`（避免叠加过曝）；叠加后**外壳变淡、内部结构透出**（如太空城的城市与三颗太阳、星际战舰的桥楼与引擎舱）。再按一次 `X` 恢复常规不透明渲染。该效果由摄像机/材质驱动，与具体物体无关，故对所有星体通用。

此外，每个粒子带一个 **`aXray` 透视衰减系数**（默认 `1.0`）：宇航员的宇航服 / 头盔设为 `0.05`，在 X 光下几乎完全淡出，从而让穿戴者的骨骼与内脏清晰可见；其他物体保持默认值，不受影响。

## 表面陆海生成

地壳（归一化半径 `t > 0.88`）的颜色不再取自半径渐变，而是用球面方向上的 **3D 值噪声 fbm** 生成：

```
n = fbm(dir * 2.2 + offset)
n = (n - 0.5) * 1.6 + 0.5      // 增强对比，海岸线更清晰
n > 0.5  → 陆地（植被绿 → 高地棕黄）
n ≤ 0.5  → 海洋（深海蓝 → 浅海青）
```

噪声哈希使用 `Math.imul` 做 32 位整数乘法（普通 `*` 会溢出 JS 双精度导致哈希退化）。
