# 二向箔 · 二维化模拟

用 Three.js 可视化《三体》中天体/物体被二向箔「二维化」的过程。

当前进度：**第八步 —— 星际战舰 / 太空城 + 三维透视**。

- 第一步：基础场景搭建（深邃宇宙背景 + 星空 + 坐标轴辅助器 + 轨道控制器）。
- 第二步：用 `THREE.Points` + `THREE.BufferGeometry` 生成实心地球点云。粒子在球体内**体积均匀**分布（半径取 `R·u^(1/3)`）。
- 第三步：用 `THREE.ShaderMaterial` 替换粒子材质，手写 GLSL 顶点/片元着色器实现降维：光速跌落面的碰撞检测、Z 轴压扁、以及基于原深度的**指数级面积膨胀**。
- 第四步：加入 `EffectComposer` + `UnrealBloomPass` 后期处理：处于降维边界时输出 **HDR 纯白**产生刺眼闪光；跌落扩散后冷却为星系般的冷色。
- 第五步：
  - 粒子数提升到 **80 万**，并修正膨胀指数，使二维盘**致密、实心、不掏空中心**；
  - 用 3D 值噪声（fbm）在球面生成**陆地与海洋**（绿/棕陆地 + 蓝色海洋，含海岸线过渡）；
  - **点击开始**：加载后显示启动界面，点击按钮（或空格/回车）才开始降维；
  - **慢速播放**：`[` / `]` 调节时间倍率（0.05× ~ 4×），`P` 暂停；
  - **远端视角**：`V` 一键切换到能一眼看全整个二维盘的远景。
- 第六步：
  - 粒子数提升到 **150 万**；
  - 新增 **侧视视角**（`S`）：低仰角贴着盘面观察，可看清二维盘各部分向外流动的方向；
  - 修正发光：**跌落凝固后的粒子恢复常规亮度（不再发光）**，只有正在跌落的边界才发白光触发 Bloom。
- 第七步：
  - 支持**切换多个有内部结构的物体**（`1`–`5` 或左上角按钮）：类地行星 / 恒星 / 气态巨行星（含冰环）/ 人造母舰 / 岩质小行星；
  - **修正二维盘内核稀疏**：把膨胀映射从“幂曲线”改为**面积均匀映射**（见下），二维盘变为均匀实心；
   - **修正行星环消失**：主体之外（`ρ > R`）改为线性外延，行星环在二维化后表现为盘外的独立环。

- 第二十四步：
  - 新增第二种**降维方式「极向同心展开」**（与原「平铺投影」并列，左上角面板按钮或 `M` 键切换，`localStorage` 全局持久化，跨会话保留）：
    - 模拟「先接触二维平面的原子先二维化，下一层挤占上一层空间并把它往外推」的物理图景：箔面**自南极（−端）升起扫向北（+端），接触即降维**（粒子被扫过量 `s = planeZ − h`）；
    - **极坐标展开映射**：粒子的**经度**（绕扫描轴的方位角）→ 二维盘上的**极角**；粒子**被接触的先后次序**（由沿轴坐标决定）→ **极半径** `r2D = u_diskR · min(planeZ−h, span)/span`——刚接触的截面落在**盘心**，随扫描推进被后层不断推向外圈；最终**北端（最后接触）居圆心、南端（最先接触）在最外圈**，地心物质位于中间环带（环带密度 ∝ 截面积，赤道环最密）；
    - **横向位置按 `q` 混合**：未跌落时（`q=0`）完整保持三维立体形状，跌落过程中平滑形变到极坐标展开——三维形态、融化、发光、白热边界与平铺模式完全一致；
    - 终态是一个层次分明、无遮挡的**「地球基因年轮圆盘」**：每个环 = 该高度的横截面成分混合色（两极环带近纯地壳、中部环带地核/地幔/地壳混合），每粒子保留原配色；
    - 盘面半径 `u_diskR = 3R`（紧凑），极小散布抖动避免未推开时叠在数学点上；扫描轴上的粒子经度不稳定，用 hash 角兜底；
    - **三轴可选**（`N` 键或按钮循环 Z/X/Y）：每个物体在注册表中带**推荐扫描轴**（长条体用其长轴：星际战舰/水滴/空间站/客机/高铁/彗星→X，宇航员/DNA→Y，其余→Z），切入极向模式或切换物体时自动套用，仍可手动改；
    - **扭曲与发光完全复用原实现**：`q = smoothstep(0, u_band, s)` 过渡、`vSince = s/u_band` 驱动 HDR 白热边界 → 高斯冷却 → Bloom，片元着色器零改动；`X` 透视、`[` `]` 变速、`P` `V` `S` `R` 等全部通用；
    - 相机 framing 适配：远景/侧视沿**盘面法向（= 扫描轴）**取景，自动运镜终距按 `u_diskR` 计算；
    - **扫描起止点自动覆盖物体三轴最大跨度**并预留一个过渡带厚度（否则如高铁道砟 ±2.4R 超出 `R+6`，最外段永不扫完、次外段冻结在过渡态）。
- 第二十五步：
  - 极向模式增加「**跌入 → 展开**」两段式视觉（与平铺投影的手感对齐）：

## 二维化的数学模型

设粒子原始坐标为 `p = (x0, y0, z0)`，跌落面位置 `planeZ = u_startZ - u_speed·u_time`（推进到 `u_endZ` 后停止）。

1. **碰撞检测**：`swept = z0 - planeZ`，`swept ≥ 0` 表示已被平面扫过。
2. **降维进度**：`q = smoothstep(0, u_band, swept)`，由 0 平滑过渡到 1。
3. **Z 压扁**：`z2 = mix(z0, planeZ, q)`，粒子 Z 逐渐塌缩到跌落面。
4. **面积膨胀（质量守恒）**：保持角向 `dir = normalize(x0, y0)`，按半径分段映射：

   ```
   growth = exp(u_exp · q)                          // 整体指数膨胀
   // 主体（ρ0 ≤ R）：面积均匀映射为实心盘
   cdf    = (R³ - (R² - ρ0²)^1.5) / R³              // 球体投影中 ρ<ρ0 的粒子占比
   frac   = sqrt(cdf)                               // 面积均匀 ⇒ 目标半径 ∝ √cdf
   // 主体之外（ρ0 > R，如行星环）：线性外延，保持相对位置
   frac   = 1 + (ρ0 - R)/R
   rho2   = R · growth · frac
   r2     = mix(rho0, rho2, q)                      // 未碰撞时保持原位
   xy2    = dir · r2
   ```

   - 主体用 `r ∝ √cdf` 得到**表面密度恒定**的实心盘 —— 不会像幂曲线（`x^α, α<1`）那样把粒子全推到边缘、掏空中心。
   - 主体之外**线性外延**（而非 clamp）：行星环等外部结构被推到盘外的独立环，不会被压到同一边缘半径而消失。相机 framing 用物体的最大横向半径 `currentExtent`，保证环也在画面内。

所有计算都在 GPU 上完成，`position` 缓冲区始终保持原始坐标（每帧只更新 `u_time` 一个 uniform）。

## 极向同心展开（第二种降维方式）

`M` 键切换到极向模式后（`u_mode = 1`），顶点着色器改用以下模型（扫描轴可选 Z/X/Y，`u_axis`）：

```
planeZ = u_endZ + u_speed·t（clamp 至 u_startZ）  // 接触式单面扫描：箔面自南极(−端)升起扫向北(+端)
s    = planeZ − h                       // h = 粒子沿扫描轴的坐标；s<0 未被接触
q    = smoothstep(0, u_band, s)         // 过渡扭曲（与平铺模式一致）
rel  = clamp(s − (u_startZ − u_pHi), 0, span)       // span = u_pHi − u_pLo
r2D  = u_diskR · rel / span             // 扫描完成时：北端→0(圆心)，南端→u_diskR(最外圈)
φ    = atan2(横向分量 b, a)             // 经度 → 极角（轴上粒子用 hash 角兜底）
```

- **接触即降维**：箔面本身就是相变波前——「先接触二维平面的原子先二维化」由接触关系直接实现（早期版本曾用镜像扫描面，因可见接触次序与降维次序矛盾而废弃）；
- `rel` 随 `planeZ` 增长——每个已二维化截面**持续被后接触的层向外挤**，终态半径只由「被接触的先后次序」决定，与《三体》「下一层挤占上一层空间」的图景一致；
- 环带线密度 ∝ 该高度截面积（`R²−h²`），赤道环最密、两极稀疏，天然形成**年轮**疏密；
- 发光管线（`vSince = s/u_band` → HDR 白热 → 高斯冷却）与片元着色器**零改动**。

## 辉光与能量释放（后期处理）

顶点着色器把「距开始降维那一刻的归一化时间」`vSince = (z0 - planeZ) / u_band` 传给片元着色器，片元中：

```
heat   = vSince > 0 ? exp(-vSince² · u_cool) : 0   // 边界处 ≈1，随时间衰减
cooled = clamp(vSince, 0, 1)                        // 冷却进度
col    = mix(galaxy, hotWhite, heat)                // 冷却色 → HDR 纯白
```

- `heat` 让刚被扫过的粒子输出 `vec3(3.5)` 的 HDR 纯白，`UnrealBloomPass` 阈值 `1.0` 只提取这些 >1 的高亮，形成刺眼闪光。
- `cooled` 让粒子在冷却时**保留物体原本的配色**（不再整体偏蓝），仅做明暗抖动形成星点；同时把亮度限制在 `<1`，避免凝固后持续辉光。
- 后期管线使用 **HalfFloat 渲染目标**，以保留 >1 的亮度，否则会被裁到 1 而失去闪光效果。

## 可调参数（`uniforms`）

- 左键拖拽：旋转视角
- 滚轮：缩放
- 右键拖拽：平移
- `[` / `]`：降低 / 提高播放倍率（慢速播放）
- `P`：暂停 / 继续
- `V`：切换远景「远端俯视」（一眼看全整个二维盘）
- `S`：切换「侧视」（贴着盘面看二维盘各部分的流动方向）
- `X`：切换**三维透视（X 光）**——粒子转半透明叠加，看穿外壳观察内部结构（所有星体通用）
- `R`：重放当前物体（回到启动界面）

## 三维透视（X 光）

按 `X` 开启透视后，粒子材质切换为 **半透明 + 叠加混合**（`transparent` / `depthWrite=false` / `AdditiveBlending`），片元着色器中的 `u_xray` 把颜色乘 `0.45`、并把单点 `alpha` 压到 `0.028`（避免叠加过曝）；叠加后**外壳变淡、内部结构透出**（如太空城的城市与三颗太阳、星际战舰的桥楼与引擎舱）。再按一次 `X` 恢复常规不透明渲染。该效果由摄像机/材质驱动，与具体物体无关，故对所有星体通用。

此外，每个粒子带一个 **`aXray` 透视衰减系数**（默认 `1.0`）：宇航员的宇航服 / 头盔设为 `0.05`，在 X 光下几乎完全淡出，从而让穿戴者的骨骼与内脏清晰可见；其他物体保持默认值，不受影响。

## 表面陆海生成

地壳（归一化半径 `t > 0.88`）的颜色不再取自半径渐变，而是用球面方向上的 **3D 值噪声 fbm** 生成：

```
n = fbm(dir * 2.2 + offset)
n = (n - 0.5) * 1.6 + 0.5      // 增强对比，海岸线更清晰
n > 0.5  → 陆地（植被绿 → 高地棕黄）
n ≤ 0.5  → 海洋（深海蓝 → 浅海青）
```

噪声哈希使用 `Math.imul` 做 32 位整数乘法（普通 `*` 会溢出 JS 双精度导致哈希退化）。
