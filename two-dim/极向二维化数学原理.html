00核心思想 —— 序贯降维与空间挤占（为什么细节不丢失）

两种方案回答的是同一个问题：如何把三维体积无重叠、无遗漏地重排进二维平面。 平铺投影（另一页面）用「面积指数膨胀」换取投影密度均衡；本方案（极向同心展开）则 彻底放弃投影，改用「降维次序」来编码空间——它来自对原著降维过程的如下直觉：

「先接触二维平面的原子会先二维化，而下一层原子二维化会挤占上一层的空间， 把上一层的画面往外推挤，这样周而复始直到降维完成，才能做到所有细节全部不丢失。 理论上，地球如果从南极开始二维化到完成，画面的最外一圈是南极，最内一圈是北极， 而中间那一圈才是地心。」

专业化重述——降维以一道沿极轴自南向北推进的相变波前（即箔面本身，接触即降维）： 箔面每抵达一层物质，该层原子即时完成「三维 → 二维」的相变；由于二维像平面不具备第三维自由度， 已降维物质在平面内占据的径向席位满足不可入性——后继截面完成降维时无法与先前的像重叠， 只能把先前已成像的画面沿径向整体外推一个层厚，为新一层让出靠内的席位。 该迭代周而复始，等价于按「被箔面接触的先后次序」构造一个保序单射：

次序 s = planeZ − h ← 箔面位置减去粒子轴向坐标 h（先接触者 s 大） 终位 r∞ = r_disk · (u_pHi − h) / span ← 次序单调决定终态极半径（先接触 → 居外圈） 生长 r = r∞ · s / (u_startZ − h) ← 每层自盘心长向终位：刚接触即从盘心生长，持续被外推（无死区）

由此得到三条直接推论：

· 无交叉、无重叠（细节零丢失）：次序 s 与极半径 r 一一对应且单调， 映射是拓扑同胚的单射——每个原子都有唯一确定的像，任何两层在像空间中永不交织；
· 环带宽度 ∝ 截面积（体积 → 面积守恒）：由体积守恒，层厚 dh 分得的环带宽 dr ∝ A(h) = π(R² − h²)，故赤道环（地心所在层面）最宽、两极环最窄， 面密度处处一致；
· 极限定位：最先扫过的南极层位于像的最外缘（r = r_disk）， 最后扫过的北极层收缩至圆心（r → 0），地心所在赤道层居中间环带—— 二维像成为一幅「地球基因年轮」：由外向内依次读出南极大地剖面。

01接触即降维 —— 单面扫掠（波前就是箔面本身）

白色箔面（planeZ）自南极向北极匀速推进，它与哪层物质接触，哪层就即时降维—— 「先接触二维平面的原子先二维化」直接由接触关系实现，无需任何辅助面。 粒子被扫过的量 s = planeZ − h 大于零即已降维，s 越大表示被接触得越早—— 这个「越早」正是后面极半径的来源。拖动滑块观察箔面自下而上的扫掠：

planeZ（箔面 = 相变波前）：自南(−端)向北(+端)匀速推进 s = planeZ − h > 0 ⟺ 粒子已降维；s ↗ 表示接触得更早（被挤得更靠外）
设计演进：早期版本曾用「镜像扫描面」（显示箔面自北向南、波前取其关于区间中点的镜像 hp = u_startZ + u_endZ − planeZ，两者相向而行），以便复用平铺投影的镜头轨迹。 但那样「可见的接触次序」（北先）与「降维次序」（南先）相互矛盾，违背「先接触者先二维化」。 现已改为接触式单面扫描：箔面轨迹服从物理叙事，镜头跟随物理。

02次序 → 极半径 —— 年轮圆盘（外圈南极 · 圆心北极 · 中环地心）

把被扫次序直接翻译成极半径：每一层横截面（纬度带）获得一整圈环带， 环带宽度 ∝ 该层截面积——赤道环最宽。左：球体侧视按纬度带着色； 右：像平面俯视，随箔面推进自盘心向外逐环生长（挤占外推）。注意终态的三条定位： 最外圈 = 南极（最先接触）、圆心 = 北极（最后接触）、中间宽环 = 地心。

r∞ = r_disk · (u_pHi − h) / span （终态年轮位：span = 物体沿极轴的总跨度） r2D = r∞ · (planeZ − h) / (u_startZ − h) （自盘心长向终位：s=0 落盘心，被后层持续外推，无死区） 角度 φ = 粒子绕极轴的方位角（保持不变 → 环带内成分与原截面一致）
南极冠（→ 最外圈） 南中纬 赤道带（地心 · → 中间宽环） 北中纬 北极冠（→ 圆心）

03综合演示 —— 接触、摊开（挤占动力学全流程）

把前面所有数学装在一起：左（侧视）箔面自下而上推进（接触即降维），粒子被箔面接触的 瞬间轴向即压平贴合箔面（白热边界紧贴箔面、随箔面上行）；右（俯视）压平的粒子再横向「摊开」—— 落向盘心，把已成像画面层层向外挤占，圆盘由内向外生长。两段式进度 qFall（接触即压平）与 qSpread（摊开，用 3 倍缓冲带）分离， 复现正片「接触即二维化、随即摊开」的动效节奏。

04平铺投影的原理 —— 以及两种方案的对照

平铺投影（见《二维化数学原理》交互演示） 采取与极向完全不同的策略：放弃「次序」，改用「面积膨胀 + 密度均衡」。 设粒子原坐标 p = (x0, y0, z0)，跌落面 planeZ 自上而下推进：

降维进度 q = smoothstep(0, u_band, z0 − planeZ) ← 被扫过即开始 高度塌缩 z2 = mix(z0, planeZ, q) ← 全体粒子同时向箔面跌落 方向保持 dir = normalize(x0, y0) ← 俯视方位角不变（像一张照片） 面积膨胀 growth = exp(u_exp · q) ← 复利式摊开，面积 ∝ growth² 密度均衡 cdf(ρ0) = (R³ − (R²−ρ0²)^1.5) / R³ ← 球投影「中心浓、边缘淡」的累积占比 像半径 r = R · growth · √cdf ← 按排名发座位 → 处处等密度 环外结构 r = growth · ρ0（ρ0 > R，如行星环） ← 线性外延，等比放大不变形

平铺投影中，同一方向上的所有层（南极到北极）被沿轴向压叠到同一个像点上—— 信息没有丢，但被「混合」了：盘上每一点的颜色是整条视线柱内物质的叠加。 而极向展开把这条视线柱拉开成一段环带：层与层沿半径排列、互不重叠。 拖动滑块对比同一批粒子的两种终态（两盘按各自比例尺显示，均远大于原投影）：

注意两图的颜色分布：平铺盘中五种纬度带在每一点混合（视线柱叠加， 靠 CDF 均衡保住密度）；极向盘中五种纬度带分离成同心环（外圈南极 → 中环地心 → 圆心北极， 靠单射保住细节）。
